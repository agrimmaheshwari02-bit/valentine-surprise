## QUICK REFERENCE - COMMON ISSUES

### Customer uploaded low-quality photo

- [ ] Message customer: "Hey! The photo quality is a bit low. Can you send the original high-res version? It'll look much better!"

- [ ] Or use AI upscaler: https://imgupscaler.com/

### Customer wants revision

- [ ] Minor fix (typo/spelling): FREE, fix immediately

- [ ] Major change (new photo/rewrite): ₹99 extra

- [ ] Set clear boundary: "Happy to fix typos! For major changes like new photos, there's a ₹99 revision fee."

### Customer late to provide info

- [ ] Send reminder: "Hey! Just need the form filled out to start building your page. Link: [form]"

- [ ] If still no response after 24h: "Your delivery slot is reserved until [date]. Let me know if you're still interested!"

### Technical issue on live page

- [ ] Check GitHub Pages status

- [ ] Re-test URL

- [ ] If broken, roll back: git revert HEAD and redeploy

- [ ] Apologize and offer discount on next order

## BATCH PROCESSING TIP

If you have 5+ orders, process in batches:

1. Batch 1 (Morning): Intake & Build (3-5 orders)

2. Batch 2 (Afternoon): Quality Check & Deploy

3. Batch 3 (Evening): Delivery & Follow-ups

This way you're in "build mode" once, not context-switching per order.
