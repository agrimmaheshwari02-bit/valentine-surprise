# 📋 GOOGLE FORM SETUP GUIDE

Step-by-step guide to create your order intake form.

---

## 🎯 FORM PURPOSE

This form collects all information needed to build a customer's personalized page:

- Personal details

- Message content

- Photos

- Customization preferences

Goal: Get everything in one submission = faster delivery

---

## ⚡ QUICK SETUP (10 MINUTES)

### Step 1: Create New Form

1. Go to: https://forms.google.com

2. Click: + Blank form

3. Title: "Valentine Surprise Page - Order Details"

4. Description: "Fill this form to create your personalized surprise page! Takes ~5 minutes."

---

### Step 2: Add Questions (Copy-Paste These)

#### SECTION 1: YOUR INFORMATION

Question 1: Your Full Name

- Type: Short answer

- Required: ✅ Yes

- Description: "What's your name?"

Question 2: Your Email

- Type: Short answer

- Required: ✅ Yes

- Validation: Email

- Description: "We'll send confirmation here"

Question 3: Your WhatsApp Number

- Type: Short answer

- Required: ✅ Yes

- Description: "With country code (e.g., +91 98765 43210)"

---

#### SECTION 2: ABOUT YOUR PARTNER

Question 4: Partner's Name

- Type: Short answer

- Required: ✅ Yes

- Description: "⚠️ Double-check spelling! This will appear on the page."

- Example: "Priya"

Question 5: How did you two meet?

- Type: Paragraph

- Required: ✅ Yes

- Description: "Share your relationship story in 2-3 sentences. This helps us write a personal message!"

- Example: "We met at a coffee shop last year. She was late, I was nervous, but we instantly clicked."

#### SECTION 3: YOUR MESSAGE

Question 6: What do you love about them?

- Type: Paragraph

- Required: ✅ Yes

- Description: "List 5+ things you love or appreciate. Be specific!"

- Type: Paragraph

- Required: ✅ Yes

- Description: "Describe one special moment you shared. This will be part of your message."

Question 8: What You Want to Say (Optional)

- Type: Paragraph

- Required: ❌ No

- Description: "If you want to write your own message, paste it here. Otherwise, we'll write it based on your answers above."

- Type: Short answer

### Step 3: Configure Form Settings

Click the Settings ⚙️ icon:

General:

- ✅ Collect email addresses

- ✅ Response receipts: Always

- ✅ Respondents can: Edit after submit (❌ Uncheck this)

- ✅ Limit to 1 response

Presentation:

- ✅ Show progress bar

- ✅ Shuffle question order (❌ Uncheck this)

- Confirmation message:

 ```

 Thanks! 🎉

 We've received your details. Your surprise page will be delivered within 48 hours!

 We'll message you on WhatsApp when it's ready.

 Questions? WhatsApp us at [your number]

 ```

Quizzes:

- Leave disabled

---

### Step 4: Set Up Responses

Click Responses tab:

1. ✅ Enable "Accepting responses"

2. Click the Google Sheets icon

3. Create new spreadsheet: "Valentine Orders"

4. This will auto-populate with responses

Configure notifications:

- Click ⋮ (three dots) → "Get email notifications for new responses"

- ✅ Enable this so you get instant alerts

---

### Step 5: Get Your Form Link

1. Click Send button

2. Click Link icon (chain symbol)

3. ✅ Shorten URL

4. Copy the link

5. Save this for your WhatsApp messages!

Optional: Use bit.ly to create a custom short link:

- Example: bit.ly/valentine-order

## 📊 MANAGING RESPONSES

### Google Sheets Setup:

When you get responses, they appear in your connected sheet with columns for each question.

Add These Extra Columns:

- Status - (New / Building / Delivered / Complete)

- Order Number - (001, 002, 003...)

- Delivery URL - (Link to deployed page)

- Notes - (Any special requests or issues)

- Testimonial - (Did they provide feedback?)

Color code rows:

- 🟢 Green = Delivered

- 🟡 Yellow = Building

- 🔴 Red = Issue/Waiting

### Automated Workflow (Advanced):

Use Google Apps Script to:

1. Send auto-confirmation email when form submitted

2. Notify you on Telegram/Slack

3. Create tasks automatically

Skip this for MVP - manual is fine!

## 🚨 COMMON FORM MISTAKES TO AVOID

### Customer Errors:

❌ Wrong partner name spelling

→ Add warning: "⚠️ Double-check spelling!"

❌ Low quality photos

→ Add example: "Upload original quality, not compressed"

❌ Unclear messages

→ Provide examples in description

❌ Missing payment proof

→ Make it required field

### Your Errors:

❌ Too many questions

→ Keep it under 15 questions (5 min to fill)

❌ Confusing wording

→ Use simple, clear language

❌ No examples

→ Add examples for every question

❌ Required fields for optional things

→ Only required what you absolutely need

## 🆘 TROUBLESHOOTING

"File upload not working on mobile"

- Check Google Drive storage space

- Ensure file type allowed: Images

- Max size: 10MB (reduce if needed)

"Not getting email notifications"

- Check spam folder

- Re-enable in form settings

- Use Google Sheets + conditional formatting instead

"Responses not showing in Sheet"

- Refresh the sheet

- Check if sheet is still connected (Responses → View in Sheets)

- Reconnect if needed

"Customer can't submit"

- Check "Accepting responses" is ON

- Verify all required fields have answers

- Check file upload limits
